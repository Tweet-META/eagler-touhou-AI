# eagler-touhou-ai

面向 Eagler Touhou 本地 AI 队友的轻量避弹核心。C++17 实现，可嵌入原生作品，也可编译为 WebAssembly 接入网页版。

对应 [eagler-touhou #144](https://github.com/Ritosa2333/eagler-touhou/issues/144)。提供基础避弹、独立座位输入接口、浏览器演示，以及[红魔乡本地合作接入](integrations/th06/README.md)：P1 真人 + P2 AI，使用作品已有的多人战斗与资源规则。

[妖妖梦本地合作接入](integrations/th07/README.md)复用同一套实力、配合与调参选项，入口为 `/th07.html`。幽明结界期间继续避弹，不把结界倒计时当作无敌时间。

永夜抄、风神录、地灵殿、星莲船和绀珠传的本地合作入口为 `/preview.html`。页面可选择作品、双方机体和难度，P1 真人操作，P2 使用 AI。每作运行一个游戏实例，采用对应多人版本的战斗与资源规则。实力、配合方式和高级参数在右侧调整。

[主站本地扩展](integrations/browser-extension/README.md)支持红魔乡及上述五作，接管当前客户端的联机座位。

## 默认策略

- 只看未来 **12 帧**，每 3 帧展开一次，保留 **8 条路线**。
- 低速九方向（含静止）与高速八方向，共 17 种动作。
- 剪掉预测会撞的路线，合并相近且第一步相同的候选。
- 按安全距离、目标位置、贴边、移动量和换方向代价评分。
- 每次只执行路线第一帧，下一逻辑帧重新计算。
- 先筛除不可达区域的危险物，再用包围盒树裁剪距离查询。
- 运算次数和危险物容量均设上限，输出搜索完成度和预算状态。

支持圆弹、旋转矩形及胶囊形激光片段。圆弹检查两帧之间的相对运动，避免高速弹直接穿过自机时被漏掉。在通过碰撞检查的候选中，收取道具和处于敌人下方会获得评分奖励。红魔乡接入另支持跟随／分别压制和保命放雷：搜索未找到能覆盖完整预判窗口的安全路线时，立即提交正常放雷按键；预算耗尽或快照无效不触发，所有按键还可统一设置输入延迟，不提供自动决死。

## 构建与试玩

需要 Node.js、C++17 编译器；Web 构建另外需要 Emscripten SDK。没有 npm 依赖。

```sh
npm run build:web -- --emsdk=/path/to/emsdk
npm start
```

打开 http://127.0.0.1:8144/ 。白色自机用方向键移动，Shift 低速；蓝色为 AI 队友。可切换弹雨、狙击、激光和混合判定，调整预判帧数、路线宽度与队友数量。

压测弹幕包括双涡旋、交叉弹墙与全方位混合；弹幕倍率可在 1～20 倍间实时调整，场内最多 4,000 个危险物。演示使用 4,096 的 AI 危险物容量，搜索预算保持不变。默认持续压测，中弹不产生无敌，避免无敌期间跳过避弹查询影响观察。页面分别显示 AI 计算、完整逻辑、Canvas 提交用时，以及显示 FPS、逻辑 Hz 与预算耗尽次数；绘制用时不包括 GPU 完成时间。

只编译原生库：

```sh
cmake -S . -B build/native -DCMAKE_BUILD_TYPE=Release
cmake --build build/native --config Release
```

完整字段、接入顺序与状态位见[接入文档](docs/INTEGRATION.md)。红魔乡本地合作与联机接管使用独立构建目录；联网接管在原输入采集位置生成按键，预测与回滚继续消费已经记录的输入。

## 来源

算法参考此前对幻枢凭依 Portable v27 所做的静态分析：有限前瞻、束搜索、动作分块和几何距离评分。本仓库是根据这些算法概念重新编写的独立实现，不包含原包、DLL、反编译代码或原游戏素材，也不承诺与参考程序行为一致。具体的游戏机制通过作品适配器补充。
