# 红魔乡真实关卡接入

在独立的 TH06 普通版 Web 构建里，让 AI 接管单个自机。使用 Eagler TH06 的菜单、关卡、渲染和游戏规则，AI 直接读取核心里的碰撞对象并返回标准按键。

## 构建

```sh
npm run build:th06 -- --source=/path/to/eagler-touhou --assets=/path/to/TH06 --emsdk=/path/to/emsdk --unifont=/path/to/unifont.otf
npm start
```

需要 CMake、Ninja、Emscripten。`--cmake` / `--ninja` 可指定完整工具路径；`--font` 可指定自己的 `msgothic.ttc`（Windows 默认使用系统字体）。资源目录需要六个 `紅魔郷CM/ED/IN/MD/ST/TL.DAT`。依赖按所参考 TH06 的 SDL 子模块提交固定下载，FreeType 使用固定提交。

默认启用作品原有 THPrac，提供 `--unifont` 或 `EAGLER_DEVELOPMENT_UNICODE_FONT` 指定字体；`--thprac=off` 可构建不含练习工具的版本。从主菜单 Practice 选机体后进入原有练习设置，可选择分段和初始资源。F12 为高级菜单、Backspace 为功能菜单、Tab 为统计面板。AI 遵从练习工具的输入占用状态，练习或高级菜单打开时停止接管，关闭后重新读取状态并规划。练习设置与高级工具沿用 TH06 的中文界面。

构建器把作品复制到 `build/th06/source` 后接入，**不修改主仓库检出**。原作资源复制到 `build/th06/assets`，打包运行文件放在 `web/th06-runtime`；这些目录均被 Git 忽略，不上传游戏数据与字体。当前构建不打包背景音乐。

打开 `/th06.html`，正常选择难度和机体进入关卡，AI 自动控制移动、低速和射击。页面按钮或 F8 可切换接管。菜单、对话、暂停、Retry、录像和 Bomb 演出期间交由玩家操作，X 手动放雷。参数滑条可以修改预判帧数与保留路线。

## 输入与状态

接入点位于 `Controller::GetInput` 的普通版返回路径。AI 替换方向、低速和射击，保留 Esc、X 等人工控制。结果进入作品原有的逻辑按键和录像记录路径；播放录像时不运行 AI。按 `gameFrames` 缓存同一逻辑帧，关卡切换、帧数回退和停止接管时重置搜索历史。

适配器没有网络传输依赖，也不进入多人构建。这里是单自机避弹验证入口；本地 AI 队友需要另接多自机座位输入。

## 碰撞采集

- 正常敌弹：读取位置、速度、碰撞矩形、已知加速度；不使用贴图尺寸。
- 敌机接触：读取有效、可交互敌机的缩小碰撞框及前后位置。
- 激光：只在临时变量里预测长度、生效计时和阶段；按帧提交旋转矩形，包括 TH06 原有宽度／长度赋值行为。
- 自机：读取实际机体速度和移动边界，用包围其方形碰撞框的圆作为保守近似。

首版不预测未来 ECL 出弹、出生动画转为正常弹的时刻、反弹、脚本转向与复杂敌机插值；每帧会从真实状态重新规划。不会推进真实游戏、消耗 RNG、改位置、改血量或增加无敌时间。界面显示实际采集与规划用时、危险物数量、查询次数和搜索完成度，供人工观察和调参。

收点从实际道具池提取位置和前后帧速度，跳过已自动吸附的道具和消弹小分点，按距离／价值排序后提交最多 32 个。残机、Bomb 和大灵力的价值高于普通点。输出目标从可伤害、可交互、可见且存活的敌人中选择最多 8 个，站在其下方并横向对齐可获奖励；不会为对齐而通过已判定危险的路线。试玩页的收点／输出权重可独立调节至 0。
